## Wah Gwaan, Young Learners! 🇯🇲🇹🇹🇧🇧🇬🇾🇧🇸

Welcome to di **Caribbean AI Curriculum** fi Primary and Prep School pickney dem!

Yuh ever wonder how yuh tablet know weh fi suggest when yuh start typing? Or how
di weather app know say rain a come before yuh even see one cloud? Well, all a dat
is **Artificial Intelligence** — or wah we call **AI** fi short!

> **AI is like teaching a computer fi think and learn, just like how yuh learn
> fi read and write at school!**

## 🏝️ What Yuh Gonna Learn

| Lesson | Topic | What It About |
|--------|-------|---------------|
| Lesson 1 | **What is AI?** | We explain AI using tings from yard — parrots, mangoes, and market day! |
| Lesson 2 | **Patterns Everywhere** | Find patterns in hurricane season, cricket scores, and bus routes |
| Lesson 3 | **Sorting and Classifying** | Sort Caribbean fruits, flags, and music like a real AI |
| Lesson 4 | **Simple Coding** | Run yuh first Python program — a Caribbean island guessing game! |
| Lesson 5 | **My First AI** | Build a likkle weather predictor dat think like AI |

## 🌊 How Fi Use Dis Section

**Teachers and Parents:**
- Each lesson designed fi take about 30-45 minutes
- Yuh nuh need no computer fi Lessons 1-3 — just paper, pencil, and imagination!
- Lessons 4 and 5 need a computer wid Python installed (ask yuh IT teacher fi help)
- Mek di pickney dem work in pairs or small groups — teamwork mek di dream work!

**Students:**
- Read each lesson carefully
- Try ALL di activities — dem fun, trust mi!
- Answer di quiz at di end of each lesson
- Check yuh answers in `quiz_answers.md` AFTER yuh try fi yuhself first!

## 🗺️ Caribbean Countries We Cover

Throughout dese lessons, yuh going learn about AI through examples from:

- 🇯🇲 **Jamaica** — Sorting mangoes at Coronation Market, Usain Bolt track patterns
- 🇹🇹 **Trinidad & Tobago** — Carnival costume classification, steelpan music
- 🇧🇧 **Barbados** — Cricket batting patterns at Kensington Oval
- 🇬🇾 **Guyana** — Sorting fruits at Stabroek Market, weather in di rainforest
- 🇧🇸 **The Bahamas** — Sorting fish at Potter's Cay, ocean pattern recognition
- 🇦🇬 **Antigua & Barbuda** — Sailing Week patterns, beach classification
- 🇱🇨 **Saint Lucia** — Banana sorting, Piton mountain recognition
- 🇻🇨 **St. Vincent & the Grenadines** — Arrowroot classification
- 🇬🇩 **Grenada** — Spice sorting (nutmeg, cinnamon, cloves!)
- 🇰🇳 **St. Kitts & Nevis** — Sugar cane harvest patterns
- 🇩🇲 **Dominica** — Rainforest animal classification
- 🇧🇿 **Belize** — Barrier reef fish patterns

## 🎯 Learning Goals

By di time yuh finish all 5 lessons, yuh will:

1. **Understand** what AI is and how it work in everyday life
2. **Recognize** patterns in di world around yuh
3. **Sort and classify** things like a computer does
4. **Run** yuh first Python program
5. **Build** a simple AI decision maker

## 📋 What Yuh Need

- A notebook and pencil (fi Lessons 1-3)
- Colored pencils or crayons (fi di activities)
- A computer with Python installed (fi Lessons 4-5)
- Yuh brain and yuh imagination!
