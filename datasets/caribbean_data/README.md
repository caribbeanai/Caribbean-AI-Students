# Caribbean AI Academy - Datasets
### "Fresh data, straight from de islands!"

This directory contains synthetic but realistic datasets covering key aspects of Caribbean life, economics, and culture. Generated by `generate_datasets.py`, these datasets are designed for students learning data science, machine learning, and AI.

---

## How to Generate

```bash
cd datasets/caribbean_data/
python generate_datasets.py
```

All CSVs will be created (or overwritten) in this directory. The random seed is fixed (`42`) so results are reproducible -- same seed, same coconut tree every time!

---

## Dataset Descriptions

### 1. `tourism.csv` - Caribbean Tourism Data

Visitor statistics across all 32 Caribbean countries and territories, 2015-2025.

| Column | Type | Description |
|--------|------|-------------|
| `country` | string | Caribbean country or territory name |
| `year` | int | Year (2015-2025) |
| `visitor_count` | int | Number of tourists that year |
| `revenue_usd` | float | Total tourism revenue in US dollars |
| `hotel_occupancy_pct` | float | Average hotel occupancy percentage |

**Notes:** Includes realistic COVID-19 impact (2020-2022 dips). Larger destinations like Dominican Republic and Jamaica have proportionally higher visitor counts.

**Example exercises:**
- Plot tourism recovery after COVID by country
- Correlate visitor count with revenue
- Compare tourism trends across islands

---

### 2. `weather.csv` - Caribbean Weather Patterns

Monthly weather observations for every Caribbean territory, 2015-2025.

| Column | Type | Description |
|--------|------|-------------|
| `island` | string | Caribbean country or territory |
| `year` | int | Year (2015-2025) |
| `month` | string | Month name (January-December) |
| `avg_temp_celsius` | float | Average temperature in Celsius |
| `rainfall_mm` | float | Total rainfall in millimeters |
| `hurricane_category` | int | Hurricane category (0 = none, 1-5 = Saffir-Simpson scale) |

**Notes:** Reflects typical Caribbean climate: dry season (Jan-Apr), wet/hurricane season (Jun-Nov). Hurricane probability peaks in August-October.

**Example exercises:**
- Visualize seasonal rainfall patterns
- Build a hurricane prediction model
- Analyze temperature trends over time

---

### 3. `agriculture.csv` - Caribbean Crop Data

Agricultural production data for major Caribbean cash crops.

| Column | Type | Description |
|--------|------|-------------|
| `island` | string | Producing country/territory |
| `year` | int | Year (2015-2025) |
| `crop` | string | Crop type: sugarcane, cocoa, banana, nutmeg, coffee |
| `yield_tonnes` | float | Annual yield in metric tonnes |
| `price_usd_per_tonne` | float | Market price in USD per tonne |

**Crops covered:**
- **Sugarcane** - Cuba, Dominican Republic, Jamaica, Barbados, and more
- **Cocoa** - Trinidad and Tobago, Grenada, Dominican Republic
- **Banana** - Saint Lucia, Dominica, Saint Vincent, Jamaica
- **Nutmeg** - Grenada ("Isle of Spice"), Trinidad and Tobago
- **Coffee** - Jamaica (Blue Mountain!), Cuba, Haiti

**Example exercises:**
- Compare crop yields across islands
- Predict future prices using time series
- Cluster islands by agricultural profile

---

### 4. `economics.csv` - Caribbean Economic Indicators

Macroeconomic data for all Caribbean nations, 2015-2025.

| Column | Type | Description |
|--------|------|-------------|
| `country` | string | Caribbean country or territory |
| `year` | int | Year (2015-2025) |
| `gdp_millions_usd` | float | Gross Domestic Product in millions USD |
| `unemployment_pct` | float | Unemployment rate as percentage |
| `tourism_pct_gdp` | float | Tourism sector as percentage of GDP |
| `agriculture_pct_gdp` | float | Agriculture sector as percentage of GDP |

**Notes:** Reflects the heavy tourism dependence of many Caribbean economies and the COVID-19 economic shock. GDP baselines are approximated from real-world figures.

**Example exercises:**
- Analyze the relationship between tourism dependence and COVID impact
- Build regression models for GDP prediction
- Compare economic diversification across countries

---

### 5. `sports_cricket.csv` - West Indies Cricket

Performance statistics for legendary and modern West Indies cricketers.

| Column | Type | Description |
|--------|------|-------------|
| `player` | string | Player name |
| `country` | string | Home country |
| `matches` | int | Total international matches |
| `runs` | int | Total runs scored |
| `wickets` | int | Total wickets taken |
| `batting_average` | float | Batting average (runs per dismissal) |

**Players include:** Brian Lara, Vivian Richards, Curtly Ambrose, Chris Gayle, and 26 more legends and modern stars.

**Example exercises:**
- Classify players as batsmen/bowlers/allrounders using clustering
- Visualize the greatest West Indies cricketers
- Compare eras (legends vs modern players)

---

### 6. `sports_track_field.csv` - Caribbean Track & Field

Personal best performances by Caribbean sprinters and field athletes.

| Column | Type | Description |
|--------|------|-------------|
| `athlete` | string | Athlete name |
| `country` | string | Home country |
| `event` | string | Event (100m, 200m, 400m, hurdles, high jump, long jump, etc.) |
| `time_or_distance` | float | Best time in seconds or distance in meters |
| `year` | int | Year of personal best |

**Athletes include:** Usain Bolt, Shelly-Ann Fraser-Pryce, Kirani James, Shaunae Miller-Uibo, Javier Sotomayor, and many more Caribbean track legends.

**Example exercises:**
- Visualize Jamaica's sprint dominance
- Analyze performance trends over decades
- Compare countries by medal-worthy performances
