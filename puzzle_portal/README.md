Find these clues scattered throughout the curriculum. Each one gives you a
piece of the final answer. **Read carefully. Think deeply. Every word matters.**

## Enter Your Answer

You have three ways to submit your passphrase:

### Option 1: Python Script (Terminal)

Run the interactive checker from your terminal:

```bash
cd Caribbean-AI-Students
python puzzle_portal/check_answer.py
```

The script will:
- Ask you to type your passphrase
- Tell you if you're right or wrong
- Give you hints if you're close
- Reveal the reward if you solve it!

### Option 2: Web Browser (Interactive)

Open the web page for a full Caribbean visual experience:

```bash
# Just open this file in any web browser:
puzzle_portal/puzzle_web.html
```

Or if you have Python installed:

```bash
cd puzzle_portal
python -m http.server 8080
# Then open http://localhost:8080/puzzle_web.html in your browser
```

### Option 3: Manual Hash Check

For the real hackers out there -- verify with SHA-256:

```python
import hashlib

your_answer = "youranswerhere"  # replace with your guess
your_hash = hashlib.sha256(your_answer.strip().lower().encode()).hexdigest()
print(f"Your hash: {your_hash}")

# The correct hash starts with: 1a7351b4...
# Run check_answer.py for the full hash and proper verification!
```
