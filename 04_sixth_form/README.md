## What Yuh Need Before Starting

- **Python confidence** -- yuh must comfortable writing classes, functions, loops
- **Basic ML knowledge** -- regression, classification, decision trees (from Form 4-5)
- **Mathematics** -- vectors, matrices, basic calculus concepts helpful but we explain as we go
- **Libraries** -- PyTorch, NumPy, Matplotlib, and we introduce more as needed

## Di Capstone Projects

### Project 1: Climate Change Predictor
Build a full prediction system fi Caribbean island climate impacts -- sea level rise,
temperature change, extreme weather events. Use regression and time series on synthetic
but realistic data fi every major Caribbean island.

### Project 2: Creole Translator
Build a rule-based translator between English and Jamaican Patois / Trinidadian Creole.
Start with di template, then extend it fi yuh own island's language patterns.

## How Fi Use Dis Module

1. Work through lessons 1-6 in order -- each one build pon di last
2. Every lesson have a quiz (10 questions) -- test yuhself honestly
3. Di two capstone projects bring everything together
4. Quiz answers in `quiz_answers.md` -- but TRY first before yuh peek!

## Fi Di Teachers

Each lesson is a standalone Python file yuh can run. Di code generate its own synthetic
data so yuh nuh need no special datasets or GPU (though GPU nice fi have). Students can
modify parameters, experiment, and extend.

Di ethics lesson is a Markdown discussion guide -- perfect fi classroom debate and essay
assignments.
