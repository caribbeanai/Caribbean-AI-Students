# Caribbean Climate Change Impact Predictor

**Caribbean AI Academy - Sixth Form Capstone Project**
**Author: Adrian Dunkley | Caribbean AI Academy**

## Overview

This project builds a machine learning model to predict climate change impacts across Caribbean Small Island Developing States (SIDS). Students will work with synthetic climate data that mirrors real patterns from Caribbean meteorological agencies.

## Objectives

- Generate and analyse synthetic Caribbean climate data (temperature, sea level, rainfall, hurricane intensity)
- Build a multi-output prediction model using scikit-learn
- Predict future climate impacts for specific Caribbean nations
- Visualise trends and communicate findings

## Files

- `data_generator.py` — Generates synthetic Caribbean climate data for 16 nations
- `main.py` — Main prediction pipeline with TODOs for students to complete

## How to Run

```bash
# Step 1: Generate the data
python data_generator.py

# Step 2: Run the predictor (complete the TODOs first!)
python main.py
```

## Requirements

```
numpy
scikit-learn
```

## Caribbean Context

Climate change is the greatest existential threat to Caribbean nations. This project gives you hands-on experience building the kind of prediction tools that CARICOM, CDEMA, and Caribbean meteorological services need.
