# Caribbean Creole Translator

**Caribbean AI Academy - Sixth Form Capstone Project**
**Author: Adrian Dunkley | Caribbean AI Academy**

## Overview

A rule-based English to Jamaican Patois (and back) translator with extension points for other Caribbean Creole languages. Students complete TODOs to expand vocabulary, improve grammar rules, and add new language pairs.

## Objectives

- Understand rule-based NLP vs statistical NLP approaches
- Build a bidirectional English-Patois translation system
- Learn about Caribbean Creole language structure and patterns
- Identify limitations and plan improvements using AI/ML

## How to Run

```bash
python main.py
```

## Features

- English to Jamaican Patois translation
- Patois to English translation
- Common phrase dictionary
- Grammar transformation rules
- Interactive mode for testing translations

## Requirements

- Python 3.7+ (no external packages needed!)

## Caribbean Context

Caribbean Creole languages (Jamaican Patois, Trinidadian Creole, Haitian Kreyol, Papiamento, etc.) are spoken by millions but underserved by technology. This project is a first step toward AI-powered Caribbean language tools.
